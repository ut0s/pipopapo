03 WAV生成は音声デバイスなしでも

● ● ●YOUR TERMINAL
# Say it in beeps.
$ pppp say "こんにちは" \
    --volume 20 --max-duration 2

# Let me know when it's done.
$ pppp notify completed

# Keep a little sound.
$ pppp render "おつかれさま" \
    -o hello.wav

03 / GET STARTED

あなたの作業にも、
ピポパポを。

CLI名は pppp。
Pluginの導入も、ひとつのコマンドから。

AVAILABLE NOW

Homebrewで、手軽に。

Homebrewからインストールできます。
次のコマンドで、すぐに使いはじめられます。

brew install ut0s/pipopapo/pppp

macOS 13以降、Apple Silicon / Intel、Linux（x86_64）に対応。
Homebrew Tap ↗ ／ v0.1.0 リリース ↗

AFTER INSTALLATION

エージェントと、いっしょに。

pppp の導入後、使うホストを選んでセットアップ。

# Codex
pppp setup codex

# Claude Code
pppp setup claude

セットアップ後はホストを再起動するか、新しいチャットを開始してHookを信頼してください。Codexの最終失敗通知はSkillから明示的に呼び出します。
